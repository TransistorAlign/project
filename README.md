# GeoLA — 零依赖 C++ 解析几何与线性代数头文件库

> 一个只依赖 C++ 标准库的 header-only 几何/线代库。
> 引入一个头文件即可使用，无需构建系统、无需链接第三方库。
> 有商业使用版本（双授权）（GPL豁免，详细信息请邮件联系谢谢）

## 这是什么？

GeoLA 是一个**单头文件、零外部依赖**的 C++ 库，用来做：

- **向量代数**：2D/3D/4D 向量，加减、数乘、点积、叉积、模长、归一化、夹角。
- **基础线性代数**：2×2 / 3×3 / 4×4 矩阵乘法、转置、行列式、求逆；小尺寸线性方程组求解。
- **解析几何**：点、直线、平面、圆、球、三角形、多边形；距离、夹角、交点、投影、面积。
- **坐标变换**：平移、旋转、缩放、正交/仿射变换（4×4 齐次坐标）。
- **二次曲线/曲面**：标准型化简所需的对称矩阵特征值/特征向量（2×2、3×3 解析解）。
- **射影几何（实验性）**：射影点/线/变换的显式齐次坐标封装，规范化与等价判定。
